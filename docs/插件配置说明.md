# 插件配置说明文档

> 本文档说明 Life-OS 平台插件的配置项、各插件的能力，以及插件数据如何参与「数据洞察」与「自动复盘」分析。
> 插件管理的统一入口：**系统设置 → 插件管理**。

## 一、插件配置模型

每个插件在 `user-data/life-plugin-config.json` 中有一条配置记录，核心字段如下：

| 字段 | 类型 | 说明 |
|------|------|------|
| `pluginKey` | string | 插件唯一键名（如 `dsh-plugin-child-resources`） |
| `name` | string | 插件显示名称 |
| `description` | string | 插件描述 |
| `enabled` | boolean | 是否启用（启用后才出现在侧边栏/看板，方法才可被 AI 调用） |
| `version` | string | 插件版本 |
| `config` | object | 插件 UI 卡片配置与功能开关（见下表） |
| `capabilities` | string[] | 插件能力标签 |
| `analyzable` | boolean | **是否支持纳入数据分析**（有数据聚合实现；只读，由系统定义） |
| `analysisLabel` | string | 分析维度简短描述（只读） |

### `config` 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `cardTitle` | string | 看板卡片标题 |
| `cardDescription` | string | 看板卡片副标题 |
| `cardIcon` | string | 卡片图标（lucide 图标名） |
| `routePath` | string | 前端路由路径 |
| `gradientFrom` / `gradientTo` | string | 卡片渐变配色 |
| `category` | string | 插件分类（core / education / productivity / finance / health / lifestyle） |
| `analysisEnabled` | boolean | **是否参与数据分析**（用户开关，默认关闭） |

> ⚠️ 更新 `config` 时为**深合并**：只覆盖传入字段，不会丢失 `category` 等已有配置。

## 二、内置插件清单与配置

### 1. 人生管理看板（核心，不可卸载）

- **键名**：`dsh-plugin-life-dashboard`
- **说明**：系统核心插件，提供目标、习惯、认知三大核心模块看板
- **可分析**：否（核心模块数据由系统直接统计，无需开关）
- **注意**：核心插件受保护，不可卸载

### 2. 儿童资料站

- **键名**：`dsh-plugin-child-resources`
- **说明**：儿童自学与启蒙资料库，提供 RAZ 分级阅读、廖彩杏绘本、牛津树、海尼曼等资源导航
- **可分析**：✅ 分析维度 = **资料数量**（资源总数、覆盖分类数）
- **开启分析**：插件详情 →「参与数据分析」开关

### 3. 番茄钟记录

- **键名**：`dsh-plugin-pomodoro`
- **说明**：番茄工作法专注计时，15/25/45/60 分钟，自动保存记录并统计专注时长
- **可分析**：✅ 分析维度 = **专注时长/次数**
- **开启分析**：插件详情 →「参与数据分析」开关（未开启时，数据洞察的番茄钟图表与自动复盘不包含专注数据）

### 4. 时间黑洞

- **键名**：`dsh-plugin-time-blackhole`
- **说明**：诚实记录被浪费的时间（发呆/刷短视频/八卦闲聊等），分类统计每日流失时间
- **可分析**：✅ 分析维度 = **浪费时间分钟数**
- **开启分析**：插件详情 →「参与数据分析」开关（未开启时，数据洞察的时间黑洞图表与自动复盘不包含浪费时间数据）

### 5. RPA 管理

- **键名**：`dsh-plugin-rpa-manager`
- **说明**：本地文件与 Excel 管理：选择本地文件夹或文件，读取 Excel 表格内容，在线编辑修改并导出保存
- **可分析**：✅ 分析维度 = **管理文件数**（本地文件夹/Excel 文件数量）
- **开启分析**：插件详情 →「参与数据分析」开关

### 6. 任务管理 GTD

- **键名**：`dsh-plugin-tasks-gtd`
- **说明**：基于 GTD 理念的任务管理系统，支持收集箱、四象限矩阵、项目分解、子任务、上下文标签
- **可分析**：否（任务数据由核心模块直接统计，无需开关）

### 7. 复盘面板

- **键名**：`dsh-plugin-review-board`
- **说明**：Markdown 式每日/每周/每月三级复盘面板：
  - **编辑**：从外部复制富文本/Markdown 粘贴自动转 Markdown，编辑后 800ms 防抖自动保存，支持编辑/预览双栏
  - **任务清单**：`- [ ] 待办` / `- [x] 已完成` 语法识别为任务，点击勾选记录完成时间，并同步回写内容中的勾选标记
  - **三级归档**：每日面板按日期归档到所属周（如 `2026-09-20` → 周 `2026-W38`），周日自动把周数据归档到所属月（`2026-W38` → 月 `2026-09`）；面板打开时兜底自动归档，也可手动点「立即归档」
  - **分享**：生成只读/可编辑两种分享链接；可编辑链接支持外网用户勾选任务写回本机
  - **发布**：一键生成自包含 HTML 发布包（`user-data/publish/`），将 HTML 上传 ShareOne 即可获得公网链接（90 天有效）
- **可分析**：否（复盘数据由面板自身归档，不参与数据洞察聚合）
- **启用方式**：系统设置 → 插件管理 → 复盘面板 → 启用（已预置启用）

### 复盘面板 AI 可调用方法

| 方法 | 参数 | 说明 |
|------|------|------|
| `review-board.savePanel` | `level`(daily/weekly/monthly), `key`(如 `2026-09-20`/`2026-W38`/`2026-09`), `content` | 保存面板 Markdown 内容 |
| `review-board.toggleItem` | `level`, `key`, `itemId`, `done` | 勾选/取消任务，记录完成时间 |
| `review-board.getView` | `level`, `key` | 查看面板（含任务统计、归档明细、待归档内容） |
| `review-board.archive` | `level`(daily/weekly), `key` | 立即归档（每日→周 / 周→月） |
| `review-board.createShareLink` | `level`, `key`, `mode`(view/edit) | 生成只读/可编辑分享链接 |
| `review-board.exportPublish` | `level`, `key`, `mode`(view/edit) | 生成发布 HTML 包（可交 AI 发布 ShareOne） |

**聊天使用示例**：
> 用户：帮我保存今天的复盘，任务有晨跑 30 分钟、阅读 20 页
> AI：`review-board.savePanel(level=daily, key=今天日期, content=## 今日复盘\n\n- [ ] 晨跑 30 分钟\n- [x] 阅读 20 页)`
> 用户：把复盘面板今天的 晨跑 勾选完成
> AI：`review-board.toggleItem(level=daily, key=今天日期, itemId=晨跑任务id, done=true)`
> 用户：把复盘面板生成一个可编辑的分享链接发给我
> AI：`review-board.createShareLink(level=daily, key=今天日期, mode=edit)`

## 三、「参与数据分析」规则（重要）

**数据洞察与自动复盘遵循统一的插件数据分析规则：**

- **核心模块数据**（习惯打卡、目标进度、笔记、人生日志）始终纳入分析，无需配置
- **插件数据**（番茄钟、时间黑洞、儿童资料站、RPA 管理等）默认**不分析**，必须在对应插件设置中开启「参与数据分析」后才纳入分析

```
插件未启用            → 该插件数据完全不参与分析
插件启用但未开分析开关  → 不参与分析（默认状态）
插件启用且开启分析开关  → 数据纳入「数据洞察」展示，并注入「自动复盘」的 AI 分析
```

### 开启方法

1. 打开 **系统设置 → 插件管理**
2. 点击目标插件（如「番茄钟记录」「时间黑洞」「儿童资料站」）查看详情
3. 在「参与数据分析」区域打开开关（仅**可分析**插件会显示该开关）
4. 开启后：
   - **数据洞察页**（`/insights`）展示该插件数据：番茄钟图表/时间黑洞图表正常显示，底部「插件数据」卡片出现摘要
   - **自动复盘**（`/review`）生成时，AI 会收到该插件数据并纳入分析建议

### 当前可分析插件

| 插件 | 分析维度 | 数据来源 |
|------|----------|----------|
| 番茄钟记录 | 专注时长 / 次数 | `pomodoro-records.json` |
| 时间黑洞 | 浪费时间分钟数 / 记录条数 | `time-blackhole-records.json` |
| 儿童资料站 | 资料数量 / 覆盖分类数 | 资源数据库 |
| RPA 管理 | 管理文件数 | 本地文件记录 |

> 其他插件后续可通过：① 在 `SEED_PLUGINS` 标记 `analyzable: true`；② 在 `InsightsService.buildPluginStats()` 添加聚合分支，接入数据分析。

## 四、插件方法与 AI 调用

插件可向 AI 助手暴露方法，AI 通过三步预检后调用：

1. **插件是否启用**：未启用 → AI 提示先启用插件
2. **方法是否存在**：不存在 → 提示不可用
3. **参数是否齐全**：缺参数 → AI 先向用户确认再执行

查看某插件的可用方法与聊天示例：**系统设置 → 插件管理 → 点击插件 → 插件详情**。

## 五、数据存储位置

- 插件配置：`user-data/life-plugin-config.json`
- 儿童资料站资源：数据库（`life_resources` 表，本地 JSON 适配）
- 番茄钟记录：`user-data/pomodoro-records.json`
- 时间黑洞记录：`user-data/time-blackhole-records.json`
- 复盘面板：`user-data/review-board-panels.json`（三级面板）/ `review-board-shares.json`（分享链接）/ `review-board-publishes.json`（发布记录）/ `user-data/publish/`（发布 HTML 包）
- AI 长期记忆：`user-data/ai-memory.json`
- AI 聊天会话：`user-data/life-ai-chat-sessions.json` / `life-ai-chat-history.json`

> 所有数据支持通过 **系统设置 → 数据管理** 按模块/插件勾选导出备份。
